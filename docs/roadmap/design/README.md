# Design & Mockups

This folder contains design artifacts, mockups, and specifications for Legal Eagle.

## Structure

- **`mockups/`** — Visual mockups, HTML previews, email templates, UI prototypes
- **`specs/`** — Design specifications, architecture documents, design decisions

## Adding Files

When creating new mockups or design docs:
1. Place HTML mockups in `mockups/`
2. Place specification documents in `specs/`
3. Use descriptive file names with dates if applicable (e.g., `2026-09-17-feature-name.md`)
4. Commit to Git (unlike the old ignored `superpowers` folder, this folder is tracked)

## Version Tracking

All design files are version-controlled in Git, so you can track changes and revert if needed.
